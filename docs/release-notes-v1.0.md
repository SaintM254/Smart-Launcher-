# Smart Launcher v1.0

A remote-friendly Android TV home screen with a favourites row, A–Z app dock, live network/time pill, and optional continue-watching cards. Includes local settings, wallpaper and icon choices, five open-license fonts, app filtering, and Safe mode.

## Setup

1. Install the APK and choose Smart Launcher as the TV's Home app.
2. Enable **Smart Launcher Home key shortcut** under Accessibility if your TV supports Home-key filtering.
3. Allow **Smart Launcher media history** under Notification access to populate the watching cards.

No display-over-other-apps permission is required. Hold Back for five seconds on the home screen to pause the Home-key override.
